# ============================================================
# VALIDATION RULES (what the test suite checks):
# ============================================================
#
# 1. LAYERS LOADED
#    Output must mention loading of layer components.
#    Look for: "embedding", "layernorm" or "layer norm", "mlp" (case-insensitive).
#
# 2. EMBEDDING SHAPE
#    Output must show token embedding dimensions.
#    Look for: "50257" and "768" on the same line or nearby.
#
# 3. LAYERNORM STATS
#    The ln_1_block0 step must show mean close to 0.
#    Parse the mean value; abs(mean) should be < 0.1.
#
# 4. MLP OUTPUT
#    The mlp_block0 step must show non-zero std.
#    Parse the std value; std > 0.001.
#
# 5. NO NaN
#    No tensor metric line should contain NaN or Inf.
#
# 6. CONV1D EVIDENCE
#    Output should mention transpose or Conv1D handling.
#    Look for: "transpose", "conv1d", "Conv1D" (case-insensitive).
#
# 7. EXIT 0
#    The process must exit with code 0.
#
# ============================================================
# NOTES ON VARIANCE:
# ============================================================
#
# - Tensor stats will vary by framework (float32 precision differences).
# - LayerNorm mean should be very close to 0 by definition.
# - MLP output std depends on weight values but should be non-trivial.
# - The exact token IDs for "What is AI?" depend on the tokenizer but
#   should be approximately 4 tokens.
