=== PART 2: Temperature — Controlling Confidence ===

Temperature = 0.5 (sharpened):
  Token 0: prob = 0.9362    <-- even more confident
  Token 1: prob = 0.0381
  ...

Temperature = 1.0 (baseline):
  [same as raw softmax above]

Temperature = 2.0 (flattened):
  Token 0: prob = 0.3363    <-- much less confident
  Token 1: prob = 0.1837
  Token 2: prob = 0.1240
  ...

# Probabilities shift: lower temperature → top token dominates.
# Higher temperature → distribution flattens, more diversity.

=== PART 3: Top-K and Top-P — Trimming the Tail ===

Top-K (k=3):
  Token 0: prob = 0.8446    <-- renormalized among top 3
  Token 1: prob = 0.1143
  Token 2: prob = 0.0421
  Token 3..9: prob = 0.0000  (filtered out)

Top-P (p=0.9, nucleus):
  [Only tokens whose cumulative probability reaches 0.9 survive]
  Token 0: prob = 0.8353    <-- cumsum = 0.7054 (keep)
  Token 1: prob = 0.1131    <-- cumsum = 0.8008 (keep)
  Token 2: prob = 0.0416    <-- cumsum = 0.8359 (keep)
  Token 3: prob = 0.0100    <-- cumsum = 0.8572 ... depends on threshold
  ...
  [tokens after cumsum >= 0.9 are filtered to 0.0000]

# Top-K is a fixed window. Top-P adapts: when the model is confident,
# fewer tokens survive; when uncertain, more survive.

=== PART 4: Repetition Penalty — Stop Saying the Same Thing ===

Previously generated tokens: [0, 1, 0, 3]  (Token 0 and 1 and 3 are seen)

Before penalty:
  Token 0: logit = 5.0, prob = 0.7054
  Token 1: logit = 3.0, prob = 0.0954

After penalty (penalty=1.2):
  Token 0: logit = 4.1667, prob = 0.5241  (reduced — was 0.7054)
  Token 1: logit = 2.5000, prob = 0.0990  (reduced relative to others)
  Token 3: logit = 1.2500, prob = 0.0284  (reduced)
  Token 2: logit = 2.0, prob = 0.0602     (unchanged — not seen)

# Seen tokens get penalized. Unseen tokens gain relative probability.
