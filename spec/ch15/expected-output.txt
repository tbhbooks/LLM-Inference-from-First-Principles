# ============================================================
# VALIDATION RULES (what the test suite checks):
# ============================================================
#
# 1. ALL 5 PARTS PRESENT
#    Output must contain all 5 section headers (PART 1 through PART 5)
#    or equivalent section markers.
#
# 2. SERVER STARTUP
#    Must show a listen address (host:port).
#    Must list the API endpoints.
#
# 3. HEALTH CHECK
#    Must show /health endpoint.
#    Must show {"status": "ok"} or equivalent.
#
# 4. COMPLETION REQUEST
#    Must show a request/response pair.
#    Response must include OpenAI fields: id, object, choices, usage.
#
# 5. SSE STREAMING
#    Must show "data: " prefix on streaming events.
#    Must show "[DONE]" sentinel.
#    Must show individual tokens being streamed.
#
# 6. ERROR HANDLING
#    Must show an error response.
#    Must include "error" object with "message" and "type" fields.
#    Must mention "invalid_request_error" or similar type.
#
# 7. OPENAI FORMAT
#    Output must contain "text_completion" or "chat.completion"
#    as the object type.
#    Must contain "finish_reason" in at least one response.
#
# 8. COMPLETION MARKER
#    Output must contain "Chapter 15 complete".
#
# ============================================================
# NOTES ON VARIANCE:
# ============================================================
#
# - The demo uses mock data, so all output is deterministic.
# - The exact completion id, timestamp, and generated text may vary.
# - Tests check structure and format, not exact content values.
# - The number of streaming tokens may vary as long as the SSE
#   format is correct and [DONE] is present.
